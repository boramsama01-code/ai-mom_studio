# Canva 폴더에서 Studio 디자인 관리하기

Canva를 디자인 원본으로 사용합니다. 연결한 폴더에서 디자인을 수정하면 Studio가 표지와 내지의 새 미리보기를 가져오고, 같은 폴더에 새 디자인을 넣으면 선택 목록에 추가합니다. Canva에서 고친 배치를 실제 제작 결과에도 사용하려면 콘텐츠 편집 화면의 **Canva 폴더 템플릿** 경로를 선택합니다.

## 처음 한 번 연결하기

1. Studio의 디자인 화면에서 **Canva 템플릿 폴더**를 엽니다.
2. Canva 연결 안내가 나오면 계정을 연결하거나 다시 연결합니다. 폴더를 읽는 권한(`folder:read`)이 추가되어 이전에 연결한 계정도 한 번 더 동의해야 할 수 있습니다.
3. 사용할 Canva 폴더 링크 또는 `FA`로 시작하는 폴더 ID를 저장합니다. 초기 폴더는 기존 Studio 디자인 14개가 들어 있는 `FAHZ9dTp-H8`입니다.
4. **지금 동기화**를 누르고 각 디자인의 미리보기가 준비되는지 확인합니다. Canva 계정 연결 여부, 마지막 확인 시각, 원고 연결 상태를 화면에서 구분해 표시합니다.

자동 확인은 Studio 서버가 실행 중일 때 2분 간격으로 작동합니다. 화면을 열거나 다시 돌아왔을 때도 최신 상태를 조회합니다. 서버가 쉬고 있거나 Canva에서 미리보기 파일을 준비하는 동안에는 표시가 늦어질 수 있습니다. 급한 변경은 **지금 동기화**로 확인할 수 있습니다.

## 평소에 디자인 수정하기

1. 연결한 Canva 폴더에서 원하는 디자인을 엽니다.
2. 표지와 내지의 글꼴, 색상, 배치, 사진을 수정합니다.
3. Canva 저장이 끝나면 Studio에서 해당 디자인의 각 페이지 미리보기를 확인합니다.
4. 콘텐츠 편집 화면에서 Canva 폴더의 디자인을 선택하고 저장한 원고로 제작합니다.

**Canva의 배치·이미지와 기본 사진 출처를 유지하고 저장된 원고를 채웁니다.** 이 경로에서는 Studio의 별도 AI 이미지 선택이 Canva 원본 사진을 교체하지 않습니다. 사진까지 바꾸려면 Canva 디자인에서 수정해 주세요. 사진 출처도 원본을 사용하며, Studio에서 사진 출처 문구를 직접 편집한 경우에는 그 문구를 반영합니다. 완성된 8장 결과는 기존 최종 검토·발행 준비 흐름에서 확인합니다.

새 미리보기가 준비되는 동안 마지막 정상 미리보기를 보여줄 수 있습니다. 화면에는 **이전 미리보기**라고 표시하며, 최신 버전 확인이 끝나기 전에는 새 제작을 시작하지 않습니다. 이미 저장한 원고와 과거 제작 결과는 폴더의 디자인 수정 때문에 덮어쓰지 않습니다.

## 새 선택지 추가하기

가장 간단한 방법은 원고가 연결된 기존 8장 디자인을 **복제**하는 것입니다. 복제본에 새 이름을 붙이고 같은 폴더에 넣은 다음 자유롭게 꾸밉니다. 원고 입력에 쓰는 텍스트 요소와 라벨을 유지하면 별도 코드 변경 없이 다시 사용할 수 있습니다. 텍스트 요소를 삭제하고 새로 만들었다면 라벨도 다시 연결해야 할 수 있습니다.

처음부터 만든 Canva 디자인도 폴더에 넣으면 목록과 미리보기에 추가됩니다. Studio에서 8장 원고를 자동 입력하려면 다음 조건을 만족해야 합니다.

- 페이지 수: 8장
- 각 페이지 크기: 1080 × 1350
- 순서: 표지 → 뉴스 요약 → 의미 → 질문 → 두 관점 → 개념 → 활동 → 마무리
- 텍스트 필드: 아래의 46개 라벨을 모두 연결

다른 구성의 디자인에는 **구성 확인 필요**, 텍스트 연결이 빠진 디자인에는 **원고 연결 필요**를 표시합니다. 브랜드 템플릿은 Canva에서 일반 디자인으로 복제해 연결 폴더에 넣습니다.

## 새 디자인의 원고 필드 연결

Canva의 대량 제작(Bulk Create)에서 텍스트 요소에 아래 이름을 라벨로 연결합니다. 대소문자와 밑줄을 그대로 유지합니다. 원고로 교체할 수 있는 라벨은 아래 46개이며, 이미지 필드는 그대로 둘 수 있습니다. 이 중 사진 출처 3개(`P01_IMAGE_CREDIT`, `P04_IMAGE_CREDIT`, `P07_IMAGE_CREDIT`)는 직접 편집한 출처가 있을 때만 교체합니다. 추가 텍스트 라벨이 있으면 과거 문구가 결과에 남지 않도록 제작 전에 확인을 요구합니다.

| 페이지 | 텍스트 라벨 |
| --- | --- |
| 1 · 표지 | `P01_TOPIC_TAG`, `P01_HEADLINE`, `P01_SUBTITLE`, `P01_IMAGE_CREDIT`, `P01_PAGE_NUMBER` |
| 2 · 뉴스 요약 | `P02_KICKER`, `P02_TITLE`, `P02_READING_BODY`, `P02_SOURCE`, `P02_PAGE_NUMBER` |
| 3 · 의미 | `P03_KICKER`, `P03_READING_BODY`, `P03_SOURCE`, `P03_PAGE_NUMBER` |
| 4 · 질문 | `P04_KICKER`, `P04_SCENARIO`, `P04_QUESTION`, `P04_IMAGE_CREDIT`, `P04_PAGE_NUMBER` |
| 5 · 두 관점 | `P05_KICKER`, `P05_VIEW_A_LABEL`, `P05_VIEW_A_BODY`, `P05_VIEW_B_LABEL`, `P05_VIEW_B_BODY`, `P05_PAGE_NUMBER` |
| 6 · 개념 | `P06_KICKER`, `P06_CONCEPT`, `P06_DEFINITION_INDEX_A`, `P06_DEFINITION_A`, `P06_DEFINITION_INDEX_B`, `P06_DEFINITION_B`, `P06_BOUNDARY_CASE`, `P06_FILL_IN`, `P06_PAGE_NUMBER` |
| 7 · 활동 | `P07_KICKER`, `P07_DURATION`, `P07_ACTIVITY_LABEL`, `P07_ACTIVITY_ACTIONS`, `P07_ACTIVITY_HELP`, `P07_IMAGE_CREDIT`, `P07_PAGE_NUMBER` |
| 8 · 마무리 | `P08_PARENT_BRAND`, `P08_BRAND_LINE`, `P08_CTA`, `P08_HANDLE`, `P08_PAGE_NUMBER` |

새로운 글을 넣었을 때 줄바꿈과 글자 넘침이 없는지는 최종 8장 결과에서 확인합니다. Canva에서 텍스트 상자를 작게 바꾼 경우에는 원고 길이나 글자 크기를 조정해야 할 수 있습니다.

## 상태가 바뀌었을 때

| 화면 상태 | 할 일 |
| --- | --- |
| Canva 재연결 필요 | 계정을 다시 연결하고 폴더 읽기 권한을 허용합니다. |
| 미리보기 준비 중 / 새 미리보기 갱신 중 | 준비가 끝날 때까지 기다리거나 잠시 후 지금 동기화를 누릅니다. |
| 원고 연결 필요 | 기존 연결 디자인을 복제하거나 누락된 텍스트 라벨을 연결합니다. |
| 구성 확인 필요 | 8장, 1080 × 1350 크기와 페이지 순서를 확인합니다. |
| 폴더에서 제외됨 | 새 제작에는 다른 디자인을 고르거나 해당 디자인을 연결 폴더에 다시 넣습니다. 저장한 원고와 과거 결과는 남아 있습니다. |
| 최근 확인 실패 | 마지막 정상 미리보기를 참고하되 Canva 원본을 확인하고 다시 동기화합니다. |

## 구현 참고

폴더 목록을 끝까지 읽은 뒤에만 삭제·이동된 디자인을 판정합니다. 변경된 버전의 미리보기 파일을 서버가 한 번 가져와 저장하며, Canva의 짧은 유효기간을 가진 썸네일 주소를 영구 주소로 저장하지 않습니다. 자동 확인은 목록과 미리보기만 갱신하고, 원고 자동 입력은 사용자가 제작을 시작할 때 실행합니다.

새 제작은 선택한 디자인의 원본 ID, 수정 시각, 페이지 ID, 필드 구성을 기록합니다. 제작 직전에 원본이나 연결 계정이 달라졌다면 다시 선택하도록 안내합니다. 미리보기 캐시는 Studio 인증 뒤에서 제공하며, 기존 디자인 목록과 기존 원고의 로컬 템플릿 키는 유지합니다.

관련 Canva API: [폴더 항목 조회](https://www.canva.dev/docs/apps/rest-apis/reference/folders/list-folder-items/), [Autofill](https://www.canva.dev/docs/apps/rest-apis/reference/autofills/).
