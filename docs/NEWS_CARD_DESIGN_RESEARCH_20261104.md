# 알리고당 뉴스 카드 편집·디자인 조사

확인일: 2026-11-04 (한국 시간). 이번 조사는 공개된 실제 디자인 샘플, 공식 문서, 제작자의 설명을 구분해 참고했다. 해외 매체의 모든 최신 게시물을 직접 분석했다는 의미는 아니다.

BBC 사례는 과거 프로젝트 자료이며 FT 저장소는 2021년 보관 처리됐다. AJ 연구도 2021년의 관찰이다. 이를 2026년의 플랫폼 규칙이나 전체 뉴스 채널의 공통 운영 방식으로 주장하지 않는다. Reuters는 편집 기준·제품 문서 확인 범위이며 Instagram 전체 캐러셀 직접 관찰로 표현하지 않는다.

보조 규격 자료로 [ONS 공식 소셜 디자인 가이드](https://service-manual.ons.gov.uk/brand-guidelines/application/social-media-design)를 확인했다. 이 자료는 1080×1350 Instagram 아트보드, 안전 여백, 출처, 큰 글자와 간결한 도표를 설명한다. ONS는 왼쪽 정렬을 권장한다. 이번 중앙 정렬은 사용자 요구에 맞춘 자체 선택이며, 해외 매체가 모두 중앙 정렬을 쓴다는 뜻이 아니다.

## 8장 편집 계약

1. **표지:** 사실에 근거한 질문·발견형 제목과 한 줄 맥락.
2. **뉴스 요약:** 누가 무엇을 했는지, 핵심 결과, 적용 조건과 한계.
3. **시사점:** 사실에서 도출하는 한 문장. 편집자의 해석임을 구분.
4. **논의:** 구체적인 상황과 열린 질문. 일반적인 감상 질문의 반복을 피함.
5. **두 가지 시선:** 각각의 주장·근거·한계. 검증된 사실과 근거 없는 부정을 동등하게 배열하지 않음.
6. **개념 정의:** 같은 단어의 서로 다른 정의 예시와 독자가 자신의 기준을 완성할 질문.
7. **추가 활동:** 실행 단계, 시간, 남길 결과물. 외부 논문·기관·전시 추천은 확인한 출처가 있어야 함.
8. **닫는 표지:** 브랜드와 짧은 마무리, 저장·팔로우 등 주 행동 하나.

이 계약은 해외 문구를 복제한 것이 아니라 조사 결과를 서비스 목적에 맞춰 재구성한 설계다. 원문 분석은 사건·주장·근거·조건·불확실성을 구조화하고, 카드 문구 작성에는 원문 근거를 함께 전달한다. 요약문만 다시 요약하면 원문의 조건과 핵심이 사라질 수 있다. 특정 카드 재작성은 사용자가 수정한 다른 카드와 배경을 보존해야 한다.

추천 활동에서 원문이나 검증된 자료에 없는 논문 제목·DOI·기관 URL을 생성하지 않는다. 확인된 외부 추천이 없더라도 기사 주장과 근거를 구분하거나 자신의 비교 기준을 만드는 자체 활동은 제공할 수 있다. 외부 추천의 확인 여부는 편집자에게 표시한다.

## 페이지별 배경 구현 원칙

- 중앙 정렬은 짧은 문장과 충분한 여백을 전제로 한다. 비교 카드는 각 영역의 문장을 독립적으로 배치한다.
- 배경이 없어도 글자만으로 읽을 수 있어야 한다. AI 그림 생성은 보기·미리보기·저장에 묶지 않는다.
- 각 페이지의 AI 생성 또는 파일 업로드는 불변 이미지 자산을 반환한다. 편집기가 배경 ID를 적용한 뒤 카드 문구를 저장해야 해당 버전에 확정된다.
- 원고 버전과 요청 UUID를 기록하고, 같은 요청은 유료 AI를 다시 호출하지 않는다. 생성 중 원고 변경·취소·채널 보관이 발생하면 최신 작업을 보존한다.
- 응답 유실은 `GET /api/channels/:cid/items/:id/card-copy/background-requests/:requestId`로 조회한다. 브라우저는 요청 UUID·페이지·버전·방식만 복구용으로 보관하며, 큰 base64 업로드 원본을 임시 저장하거나 유료 요청을 자동 재전송할 필요가 없다. 해당 콘텐츠의 배경 작업만 조회할 수 있다.
- 업로드는 PNG·JPEG·WebP 실제 픽셀을 검사하고 8MB·4천만 화소 이내로 제한한다. 정지 이미지 한 장만 JPEG로 정규화하고 메타데이터를 제거한다. 외부 이미지 주소를 서버에서 가져오지 않는다.
- 배경 자산은 콘텐츠·채널·원래 리비전 소유권과 저장 해시를 검사한다. 같은 콘텐츠의 이후 버전에서는 재사용할 수 있다.
- AI 이미지는 일러스트임을 표시하고, 실제 사건의 증거 사진으로 보이게 만들지 않는다. 사진·일러스트·그림 속 한글에 편집 문구를 의존하지 않는다.

## 라이선스와 검증 한계

BBC·Guardian·Reuters·FT의 로고, 전용 글꼴, 사진, 카드 문구를 서비스 자산으로 가져오지 않는다. 레이아웃·편집 구조만 참고하고 기존 허용된 한국어 글꼴과 자체 디자인을 사용한다. FT Story Playbook의 MIT는 소프트웨어에만 해당하며 FT 콘텐츠에는 별도 저작권이 있음을 README가 명시한다. 외부 코드는 이번 배경 기능에 복사하지 않았다.

이미지 업로드 검사는 모의 이미지와 격리된 테스트 데이터로 수행한다. 실제 유료 AI 생성, 운영 데이터 수정, Instagram 게시 성공을 이 문서로 주장하지 않는다. 실기기 키보드·IME와 외부 공급자의 실제 처리 결과는 모의 응답 기반 회귀 검사와 구분한다.
