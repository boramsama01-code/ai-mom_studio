# 카드뉴스 14종 Canva 네이티브 저장본 — 2026-11-04

## 저장 상태와 적용 범위

Canva에 새 디자인 14개를 저장하고, 저장 후 디자인 ID·편집 링크·8장 페이지 수·실제 데이터셋을 다시 조회했다. 모두 [Studio 연결본 폴더](https://www.canva.com/folder/FAHZ9dTp-H8)에 모았다. 13개 스타일은 전달받은 원본의 사본이며, 앰버크림은 하단선 3개를 수정한 r2 파생본을 새 디자인으로 가져왔다. 기존 Canva 원본, 제공된 HTML·레이아웃·자산 파일은 보존했다.

14종 × 8장 = **112개 실제 Canva 편집 미리보기**를 확인했다. 문구 필드는 **644개(스타일당 46개)**, 이미지 필드는 **89개**다. 이미지 필드 수에는 각 스타일의 8장 프로필 이미지 1개가 포함된다. 이 수치는 저장된 데이터셋 계약과 실제 편집 미리보기에 관한 확인이며, 112개 최종 PNG export 또는 실제 기사 Autofill 완료 수치가 아니다.

이 문서와 링크 카탈로그 변경은 **PR #64의 후속 변경**이다. main 병합과 Render 운영 배포는 수행하지 않았다. 실제 Canva 저장은 완료되었지만, 운영 스튜디오에 새 링크가 적용되었다고 주장하지 않는다.

## 보존한 내용과 실제 보정

### 앰버크림 r2

1·4·7장의 얇은 하단선 3개를 `y=1258`에서 `y=1290`으로 이동했다. 이미지 출처 문구의 최대 하단 `y=1278` 아래에 12px 간격을 만든다. 선의 x=72, width=720, height=2, 색상 `#FFD579`는 유지했다. Studio에 이미 있던 `cardnews14-amber-cream-v1-20261104-r2`의 세 가지 보정을 Canva 저장본에도 반영한 것이다.

새로 가져온 디자인에서 소스 스크립트 `prepare_native_requests`로 Noto Sans KR 37개 문구 필드의 normal/bold를 복원하고 기존 폭과 x/y를 복원했다. Serif 9개 필드는 유지했다. 46개 문구와 8개 이미지의 데이터셋 라벨 54개까지 포함해 165개 편집 작업을 적용했다. 문구를 다시 작성하거나 일부 문장을 삭제·대체한 보정이 아니다.

폰트 복원으로 계산된 텍스트 높이 36개가 달라져 엄격한 높이 동일성 감사는 `blocked` 결과를 보존했다. 별도 `amber-r2-font-metrics-audit.json`은 의도된 높이 차이, 문구·이미지 자산·x/y/width 보존, 선언된 레이아웃 높이 예산 통과를 확인한다. 엄격한 동일성 검사를 통과한 것처럼 결과를 덮어쓰지 않았다.

### 작은 문구의 표시 복원

실제 Canva 미리보기에서 작은 문구가 보이지 않는 문제를 발견한 4개 스타일의 7개 필드에만 폰트 호환성 보정을 적용했다. 문구 내용·필드 키·폭·x/y는 유지했다.

| 스타일 | 보정한 필드 |
|---|---|
| 시네마틱 | `P03_KICKER`, `P03_SOURCE` |
| 흑백코랄 | `P03_KICKER`, `P03_SOURCE`, `P06_KICKER` |
| 코발트페이퍼 | `P03_SOURCE` |
| 검정라임 | `P03_SOURCE` |

이외 스타일은 불필요한 폰트 재지정을 하지 않았다. 일부 사본에서 원본 native snapshot과 계산된 텍스트 높이가 달랐으며, 그 차이는 인수 기록에 남기고 실제 8장 표시와 높이 예산으로 함께 검수했다. 전 디자인의 픽셀이 원본과 완전히 같다고 주장하지 않는다.

YOU & ME의 겹친 금색 테두리는 원본 native 미리보기부터 원 대신 사각형으로 표현된다. 새 사본에도 그 표현을 보존했다. 원본 레이아웃의 radius 표현과 Canva 가져오기의 차이이며, 이번 제목 변경에서 새로 발생한 회귀가 아니다.

## Studio 연결과 기존 작업 보존

`shared/cardnews14Catalog.ts`의 `sourceId`와 `editUrl`은 위 새 저장본을 가리킨다. 기존 handoff의 ID와 편집 URL은 `originalSourceId`·`originalEditUrl`에 보존했다. 검증 출처는 `sourceVerifiedBy: 'native-save-20261104'`다. 이는 native 저장 후 페이지와 데이터셋을 재확인했다는 뜻이다.

`client/src/CanvaEditorial.tsx`의 디자인 설정 카드에서는 **Canva 저장본 ↗**으로 새 디자인을 연다. 기존 콘텐츠 편집기의 스타일 선택, 8장 자체 렌더, 저장된 문구·이미지·작업 스냅샷은 변경하지 않았다. 스타일 ID·매핑 버전·레이아웃/자산 SHA와 기존 두 스타일의 계약을 바꾸지 않았다.

`cardnews14Source()`의 `productionEnabled: false`, `autofillVerified: false`는 유지한다. 별도 `READING_CANVA_MASTER_BINDINGS`도 빈 배열을 유지한다. 저장된 디자인 링크가 존재하거나 데이터셋 키가 같다는 이유로 자동 제작을 허용하지 않는다. 이 카탈로그의 런타임 호출부는 디자인 설정의 링크 표시이며, 생성·발행 작업의 승인 근거가 아니다.

기존 `tests/cardnews14-contract.test.ts`는 원래 읽기 전용 handoff 증거인 `docs/artifacts/cardnews14-live-datasets-20261104.json`을 계속 사용한다. 조회 키만 `source.originalSourceId`로 바꿔 새 저장본 링크와 원본 데이터셋 출처를 혼동하지 않게 했다. 과거 증거 파일을 새 저장본 조회 결과인 것처럼 바꾸지 않았다.
