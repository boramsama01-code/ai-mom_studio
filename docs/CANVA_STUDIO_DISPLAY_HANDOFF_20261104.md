# 스튜디오·Canva 카드뉴스 자동제작: 전체 문구 편집 계약
작성일: 2026-11-04
상태: 구현 및 검증 기록. 디자인 생성·필드 등록·실제 출력의 완료 여부는 아래 상태표로 구분한다.

## 1. 이번 변경의 목적
**최종 결과는 인스타그램 피드용 1080×1350px(4:5) 카드 8장이다. 프레젠테이션/PPT를 제작하지 않는다.**

타깃은 중·고등학생 자녀와 학부모다. 서로의 근거·판단 기준·반례·선택을 대등하게 나누는 말투를 사용한다. 어린이 대상 설명이나 유아적인 활동 문구를 쓰지 않는다.

스튜디오에서 AI가 만든 원고와 이미지를 확인하고 직접 수정한 뒤, 그 저장값을 Canva 템플릿에 자동으로 넣는다. 사용자가 배경 이미지를 반복해서 다운로드하고 재업로드하는 절차를 운영 방식으로 삼지 않는다.

카드에 실제로 보이는 문자열은 모두 스튜디오에서 확인하고 수정할 수 있어야 한다. 제목과 본문뿐 아니라 작은 단계 표기, 출처, 페이지 번호, 이미지 설명, 활동 시간, 마지막 장 문구와 계정도 포함한다. 마지막 장의 기본 디자인은 통일하되 현재 콘텐츠의 문구 수정은 허용한다.

## 3. 스튜디오 데이터 원칙

### 본문과 표시 문구
기존 의미 필드인 headline, facts, takeaway, question, perspectives, concept, activity, outro 문구는 기존 원고 데이터에서 직접 읽는다. 같은 본문을 'Canva용 원고' 또는 통째로 복제한 display 객체에 이중 저장하지 않는다. 그래야 본문을 고친 뒤 오래된 복제값이 다시 출력되는 일을 막을 수 있다.

기존 원고에 없던 작은 표기만 페이지별 표시 설정으로 보관한다. 예: 뉴스 읽기, STEP 1~4, 주제 태그, 출처 표시, 페이지 번호, 정의 번호, 활동 시간, 보조 안내, 이미지 표기. 공통 resolver가 기본값과 현재 콘텐츠의 수정값을 합쳐 Studio와 Canva 양쪽에 전달한다.

빈 문자열로 숨김을 허용한 항목은 '값 없음'과 구별한다. 초기값 복원은 사용자가 명시적으로 선택했을 때만 한다.

### 편집 화면
각 장에 다음을 함께 둔다.
1. 현재 원고의 실제 편집 필드
2. 그 장에 표시되는 보조 문구
3. 이미지 선택·생성·재생성·크롭/밝기 설정
4. 현재 입력을 반영한 빠른 미리보기
5. 최신 Canva 출력의 상태와 확인 링크

화면에서 문구를 수정하면 저장 전에도 미리보기에 반영한다. 저장 후 다시 열어도 같은 값이 나와야 한다. 캡션은 별도 편집 영역을 유지하며 카드 문구를 고쳤다는 이유로 수동 작성 캡션을 덮어쓰지 않는다.

### 변경 추적
기존 revision, 수동 수정 보호, 잠금, 실패 복구, 입력 해시, 오래된 AI 결과 방지 규칙을 유지한다. 자동 생성이 진행되는 동안 원고가 바뀌면 이전 입력으로 생성한 결과를 최신 결과처럼 채택하지 않는다.

## 4. 이미지 연결 계약

스튜디오 생성 이미지의 저장 자산 ID를 기준으로 연결한다.

1. AI 이미지 생성 결과를 스튜디오에 저장한다.
2. 현재 콘텐츠가 선택한 이미지와 크롭·밝기 설정을 읽는다.
3. 텍스트가 없는 이미지 바이트를 준비한다.
4. Canva 자산으로 업로드하고 반환된 asset_id를 저장한다.
5. 실제 템플릿의 확인된 image 필드에 그 asset_id를 넣는다.
6. 현재 저장 원고의 text 필드를 같은 작업에 넣는다.
7. 8장 PNG 출력을 확인하고 스튜디오의 최종 출력으로 저장한다.

이미지 생성 실패 시 성공한 이전 이미지를 지우지 않는다. 배경을 다시 생성해도 수동 수정한 제목·본문·마지막 장 문구는 바뀌지 않는다. 이미지 안에 제목이나 로고를 그려 넣어 텍스트 편집이 불가능해지는 방식을 사용하지 않는다.

## 5. 최신 디자인 방향: 임팩트 보강

사용자의 최신 평가: 기존 시안은 "너무 교양 있어 보이고 임팩트가 부족하다". 차분한 종이색·작은 명조·넓은 여백만으로 구성하는 방향을 최종안으로 확정하지 않는다.

### A. 강한 사진과 큰 질문
- 화면을 크게 차지하는 피사체, 과감한 크롭, 충분한 명암 대비.
- 제목은 한눈에 읽히는 두 줄을 우선한다. 짧은 주제어만 강조색을 사용할 수 있다.
- 어두운 사진 위 밝은 제목, 또는 밝은 사진 위 짙은 제목. 사진의 어두움 자체보다 제목과 피사체의 대비를 본다.
- 예시 카피: "시험 잘 보는 AI,\n진짜 실력은?". 이는 디자인 검토용 예시이며 실기사 적용 시 본문의 사실·조건과 일치하는지 다시 검증한다.
- 배경 이미지·제목·보조 문구는 별도 편집 요소다. 제목을 AI 이미지에 구워 넣지 않는다.

### B. 사진과 선명한 타이포그래피
- 흰색/잉크색 대비에 주황·라임 등 강조색 한 가지를 사용한다.
- 큰 질문과 사진의 크기 차이, 숫자·가느다란 선·작은 출처로 정보 위계를 만든다.
- 장식용 도형이나 가짜 앱 버튼을 반복해서 OTT 화면 자체를 복제하지 않는다.
- 검정/빨강 초대형 포스터는 제목 강도의 참고 자료이며 전체 페이지를 같은 포스터로 만들지 않는다.

### 내지 연결
- 2~3장은 작은 '뉴스 읽기'와 회색 연속 본문을 중심으로 둔다. 근거와 한계를 읽을 수 있게 하고 핵심 구절에만 하이라이트를 적용한다.
- 4~7장은 작은 STEP 숫자, 실제 질문·관점·개념·행동을 크게 배치한다. 페이지 역할을 설명하는 교재형 중제목은 넣지 않는다.
- 표지에서 고른 강조색·선·페이지 표기 방식을 내지에 이어 쓴다.
- 원본 레퍼런스의 인물 위치·제목 띠·특정 도형 조합을 그대로 복제하지 않는다.
- 공통 마지막 장과 ALLligodang 프로필 1회 규칙을 유지한다.

위 46개 텍스트 계획은 가치 개념·집 활동 예시를 기준으로 한다. 과학 개념이나 선택 활동이 있는 콘텐츠는 해당 의미 필드와 필요한 요소가 실제 템플릿에 존재하는지 별도 검증한다. 기존 CardCopyV2에 V3 전용 구조를 같은 버전으로 끼워 넣지 않는다.
