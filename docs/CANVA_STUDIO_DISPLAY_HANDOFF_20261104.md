# 스튜디오·Canva 카드뉴스 자동제작: 전체 문구 편집 계약

## 최우선 적용: 전면 사진형으로 방향 변경

**최신 사용자 피드백에 따라 전면 사진 + 대형 타이포그래피 + 명암 그라데이션 방식으로 변경한다.** 기존 창형 A/B는 사용자가 거절했다. 아래에 남긴 창형 46개 텍스트·4개 이미지 계약과 Ink/Lime·Cobalt/Paper 구현 내용은 **이전 구현 기록**이며, 이를 운영 마스터로 등록하거나 활성화하지 않는다.

- 확정된 새 방향: 1080×1350, 8장. 1~7장은 사진을 전면 배경으로 깔고 페이지별 어두운 오버레이·그라데이션 위에 네이티브 텍스트를 배치한다. 2~3장 뉴스 읽기도 같은 원칙으로 본문 가독성을 확보한다.
- 새 요구 계약: **편집 가능한 네이티브 텍스트 46개 + 이미지 슬롯 8개**. 1~7장의 배경은 Studio에서 생성한 공통 원본 사진을 재사용하고, 8장은 기존 남색 마무리와 승인된 ALL 프로필을 사용한다.
- 사진에는 제목·본문·출처·STEP 등의 글자를 구워 넣지 않는다. 실제 문구는 Studio에서 미리보고 수동 수정할 수 있는 46개 필드로 유지한다.
- 세부 스타일 후보: **A 시네마틱 / B 흑백·코랄 / C 앰버·크림**. 현재 세 후보는 표지·뉴스 읽기·STEP 2를 비교하는 **래스터 비주얼 시안**이다. A는 추천 후보이며 사용자 선택은 아직 확정되지 않았다.
- 이 비교 시안을 새 프로필 코드 구현, Canva 네이티브 템플릿 등록, 실계정 자동 채움 또는 운영 배포 완료로 표현하지 않는다.
- 기존 창형 마스터의 최종 Canva 저장·운영 활성화는 하지 않았다. `shared/readingCanvaMasters.ts`의 승인 sourceId 목록은 빈 상태를 유지한다.

새 방향의 확정 사항과 미확정 사항은 [전면 사진형 카드뉴스 전환 명세](FULL_BLEED_CARDNEWS_DIRECTION_20261104.md)를 따른다. 아래 과거 기록의 ‘사용자 확정 사항’·‘최신 디자인 방향’ 등 시각 방향 표현보다 이 전환 안내가 우선한다.

## 1. 이번 변경의 목적
**최종 결과는 인스타그램 피드용 1080×1350px(4:5) 카드 8장이다. 프레젠테이션/PPT를 제작하지 않는다.**

타깃은 중·고등학생 자녀와 학부모다. 서로의 근거·판단 기준·반례·선택을 대등하게 나누는 말투를 사용한다. 어린이 대상 설명이나 유아적인 활동 문구를 쓰지 않는다.

스튜디오에서 AI가 만든 원고와 이미지를 확인하고 직접 수정한 뒤, 그 저장값을 Canva 템플릿에 자동으로 넣는다. 사용자가 배경 이미지를 반복해서 다운로드하고 재업로드하는 절차를 운영 방식으로 삼지 않는다.

카드에 실제로 보이는 문자열은 모두 스튜디오에서 확인하고 수정할 수 있어야 한다. 제목과 본문뿐 아니라 작은 단계 표기, 출처, 페이지 번호, 이미지 설명, 활동 시간, 마지막 장 문구와 계정도 포함한다. 마지막 장의 기본 디자인은 통일하되 현재 콘텐츠의 문구 수정은 허용한다.

## 3. 스튜디오 데이터 원칙

### 본문과 표시 문구
기존 의미 필드인 headline, facts, takeaway, question, perspectives, concept, activity, outro 문구는 기존 원고 데이터에서 직접 읽는다. 같은 본문을 'Canva용 원고' 또는 통째로 복제한 display 객체에 이중 저장하지 않는다. 그래야 본문을 고친 뒤 오래된 복제값이 다시 출력되는 일을 막을 수 있다.

기존 원고에 없던 작은 표기만 페이지별 표시 설정으로 보관한다. 예: 뉴스 읽기, STEP 1~4, 주제 태그, 출처 표시, 페이지 번호, 정의 번호, 활동 시간, 보조 안내, 이미지 표기. 공통 resolver가 기본값과 현재 콘텐츠의 수정값을 합쳐 Studio와 Canva 양쪽에 전달한다.

빈 문자열로 숨김을 허용한 항목은 '값 없음'과 구별한다. 초기값 복원은 사용자가 명시적으로 선택했을 때만 한다.

### 편집 화면
각 장에 다음을 함께 둔다.
1. 현재 원고의 실제 편집 필드
2. 그 장에 표시되는 보조 문구
3. 이미지 선택·생성·재생성·크롭/밝기 설정
4. 현재 입력을 반영한 빠른 미리보기
5. 최신 Canva 출력의 상태와 확인 링크

화면에서 문구를 수정하면 저장 전에도 미리보기에 반영한다. 저장 후 다시 열어도 같은 값이 나와야 한다. 캡션은 별도 편집 영역을 유지하며 카드 문구를 고쳤다는 이유로 수동 작성 캡션을 덮어쓰지 않는다.

### 변경 추적
기존 revision, 수동 수정 보호, 잠금, 실패 복구, 입력 해시, 오래된 AI 결과 방지 규칙을 유지한다. 자동 생성이 진행되는 동안 원고가 바뀌면 이전 입력으로 생성한 결과를 최신 결과처럼 채택하지 않는다.

## 4. 이미지 연결 계약

스튜디오 생성 이미지의 저장 자산 ID를 기준으로 연결한다.

1. AI 이미지 생성 결과를 스튜디오에 저장한다.
2. 현재 콘텐츠가 선택한 이미지와 크롭·밝기 설정을 읽는다.
3. 텍스트가 없는 이미지 바이트를 준비한다.
4. Canva 자산으로 업로드하고 반환된 asset_id를 저장한다.
5. 실제 템플릿의 확인된 image 필드에 그 asset_id를 넣는다.
6. 현재 저장 원고의 text 필드를 같은 작업에 넣는다.
7. 8장 PNG 출력을 확인하고 스튜디오의 최종 출력으로 저장한다.

이미지 생성 실패 시 성공한 이전 이미지를 지우지 않는다. 배경을 다시 생성해도 수동 수정한 제목·본문·마지막 장 문구는 바뀌지 않는다. 이미지 안에 제목이나 로고를 그려 넣어 텍스트 편집이 불가능해지는 방식을 사용하지 않는다.

## 5. 최신 디자인 방향: 사진을 교체해도 유지되는 템플릿

**최신 사용자 지시가 이전의 사진 중심 추천보다 우선한다.** 사진은 Studio에서 AI로 매번 생성하므로, 특정 사진의 표정·조명·크롭에 의존하는 구성을 주력으로 삼지 않는다. 제목, 색 면, 구획, 번호와 여백 자체가 임팩트를 만들어야 한다.

### 선정 기준
- 사진을 회색 사각형으로 가려도 제목과 색 면만으로 구성이 남는가.
- 밝은 사진·어두운 사진·복잡한 배경·인물 없는 사진으로 바꿔도 제목의 색과 위치를 매번 다시 정할 필요가 적은가.
- 사진 영역과 텍스트 영역이 독립된 편집 요소로 존재하는가.
- 짧은 한글 제목과 긴 한글 제목을 미리 정한 2~3줄 안에 수용할 수 있는가.
- 표지뿐 아니라 뉴스 읽기와 STEP 내지에도 같은 색·선·번호·간격을 이어갈 수 있는가.

위는 실제 새 마스터에서 앞으로 검수할 기준이다. 사진 교체 실험을 이미 통과했다는 뜻이 아니다.

### 주력 A: 색 면 + 큰 제목 + 고정 사진 창
- 단색 바탕 또는 불투명한 제목 면이 화면의 구조를 잡는다.
- 사진은 정해진 사각 창에 넣어 교체한다. 인물 누끼나 특정 자세에 맞춘 글자 배치를 기본 요건으로 두지 않는다.
- 제목과 사진의 면적·경계는 템플릿이 결정한다. 배경 사진이 바뀌어도 글자 대비를 안정적으로 유지한다.
- 참고 이미지의 여러 색을 그대로 섞기보다 검정/흰색 등 중립색과 강조색 1~2개로 정리한다.

### 주력 B: 큰 타이포그래피 + 색 블록
- 사진 없이도 구성되는 제목 페이지를 기본으로 설계한다.
- 사진을 쓰는 변형은 작은 창 또는 제목 밖의 보조 영역에 넣는다.
- 영문 한 단어를 길게 늘이는 효과, 글자 한 자씩의 수작업 변형은 긴 한글 제목 자동화의 기본으로 삼지 않는다.
- 제목은 원문 사실을 보존한 실제 질문으로 작성한다. 디자인 검토용 예시: "시험 잘 보는 AI,\n진짜 실력은?".
- 강조 구절은 원문 제목 안의 스타일 범위로 관리하고, 같은 제목을 별도 의미 필드에 중복 저장하지 않는다.
- 긴 제목 때문에 글자를 무한히 줄이거나 강제로 자르지 않는다. 넘침을 표시하고 운영자가 축약안을 선택·수정하도록 한다.

### 내지 연결
- 2~3장: 작은 '뉴스 읽기', 회색 연속 본문, 선택한 핵심 구절에만 하이라이트. 출처·조건·한계를 보존한다.
- 4~7장: 작은 STEP 숫자, 실제 질문·관점·개념·행동이 큰 텍스트가 된다.
- 동일한 그리드의 영역을 표지에서는 사진 창으로, 내지에서는 본문·두 관점·사례 영역으로 바꾸어 사용한다.
- 모든 장을 동일한 표지형 레이아웃으로 반복하지 않는다. 장별 읽기 역할에 맞춰 밀도와 사진 비중을 바꾼다.
- 공통 마지막 장과 ALLligodang 프로필 1회 규칙을 유지한다.

## 11. 승인된 원본 디자인과 스타일의 대응 검사

두 새 스타일은 동일한 46개 텍스트·4개 이미지 필드 이름을 사용하므로 필드 검사만으로는 Ink/Lime 원본을 Cobalt/Paper 버전으로 잘못 등록하는 상황을 구별할 수 없다. `shared/readingCanvaMasters.ts`의 승인 목록에서 `profileId + templateVersion + sourceId`의 정확한 조합도 대조한다. 최종 8장 미리보기 승인·병합·저장·데이터셋 확인 전이므로 현재 승인 목록은 비어 있다. 임의로 준비 중인 디자인 ID를 추가하지 않는다.

- 등록 및 신규 생성은 승인된 조합만 허용한다. 대기 작업이 실제 자동 채움 단계로 넘어갈 때도 다시 대조한다.
- Studio 스타일 선택·문구 편집·미리보기는 계속 사용할 수 있다.
- UI도 준비되지 않은 조합을 사용 가능한 마스터로 표시하지 않는다.
- 이전 Canva 결과의 가져오기·내보내기·복구에는 신규 생성용 가드를 적용하지 않는다. 기존 결과를 계속 확인하고 회수할 수 있다.
- 기존 레거시 마스터 계약은 이 새 승인 목록의 영향을 받지 않는다.

원본의 네이티브 요소·필드·이미지·진행 중 편집 트랜잭션 기록은 `docs/artifacts/reading-template-canva-manifest.json`에 보존했다. 이 파일은 복구 기록이며 런타임 준비 완료 목록이 아니다. 확인이 끝난 원본 ID만 승인 목록에 연결한 뒤 실제 계정의 등록·자동 채움·8장 출력 검증을 별도로 완료해야 한다.

검증 기록: 통합 구현 b68d50d의 로컬 관련 10파일·109테스트, 타입 검사, 양쪽 프로덕션 빌드가 통과했다. 승인 원본 대응 가드의 좁은 계약/UI 테스트 2파일·38테스트와 타입 검사도 통과했으며, PostgreSQL 회귀를 추가했다. 이 후속 변경의 원격 CI 최종 상태는 PR64 최신 HEAD에서 별도로 확인한다.
