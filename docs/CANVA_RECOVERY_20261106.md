# Canva 표지 연동 재개 기록 — 2026-11-06 KST

## 범위와 기준

사용자가 중단된 작업으로 **표지·Canva 연동**을 선택했다. 기준 운영 커밋은 `5a5c12110e03b7f5e4529612e95dee3090c7a472`, Render 서비스는 `srv-dbjep0ou01pc73f8rf80`이다. 포즈 449개 등록은 이미 완료되었으므로 다시 등록하거나 배포를 반복하지 않는다.

## 확인한 원인

- `APICore.ConversationDetailError.DetailError 오류1`의 내부 종료 로그와 HTTP 응답은 이 작업에 제공되지 않았다. 정확한 오류 코드 정의도 공식 공개 문서에서 확인하지 못했다. 대화 길이, 네트워크, 서버 장애, 자동검토 중 무엇이 원인인지 확정하지 않는다.
- 이 오류를 스튜디오의 Canva 인증 실패와 같은 사건으로 취급하지 않는다. ChatGPT 앱 자체의 오류 재발 방지를 이 저장소 수정으로 보장할 수 없다.
- 로그인된 운영 `/connections?service=canva`에서 Client ID가 실제 발급값 대신 `aimom`으로 등록된 것을 확인했다. 비밀값은 읽거나 출력하지 않았다.
- 운영 `/design`은 Canva 재연결 필요, 마지막 확인 전, 0개 디자인으로 표시했다. Canva 연결 도구로 실제 폴더 `FAHZ9dTp-H8`를 조회하면 8장짜리 디자인 14개가 모두 존재한다.
- 폴더 동기화 코드는 이미 운영에 있다. 서버의 OAuth 앱 설정이 잘못된 상태이므로 반복 재연결은 이 문제를 해결하지 못한다.

## 복구 변경

- 등록된 표지 14종, 각 8장 저장 예시와 Canva 편집 링크를 디자인 화면에 상시 표시한다. 저장본과 실시간 동기화를 명확히 구분한다.
- 알려진 임시 Client ID와 빈 설정을 OAuth 이동 전에 검사하고, 실제 설정을 고치는 경로를 안내한다. 문서화되지 않은 Canva ID 형식은 강제하지 않는다.
- 잘못된 앱 설정에서는 남아 있는 토큰을 연결 성공으로 표시하거나 토큰 갱신·인증 코드 교환 요청을 보내지 않는다.
- 원고, 기존 디자인, 폴더 내용과 인증정보를 임의로 바꾸지 않는다. SNS 게시와 유료 생성은 실행하지 않는다.

## 재개 절차

1. 이 문서, 해당 변경 브랜치 `fix/canva-design-recovery-20261106`, GitHub 검사와 운영 revision을 먼저 확인한다.
2. 같은 검사나 배포가 진행 중이면 새 실행을 만들지 않는다. 완료한 이미지 등록·템플릿 제작을 반복하지 않는다.
3. 변경을 검증한 뒤 기존 운영 서비스에 반영하고 `/design`에서 표지·내지와 구체적인 설정 안내를 확인한다.
4. 실제 Canva 자동 갱신의 남은 조건은 개발자 앱의 올바른 Client ID/secret 저장과 사용자 OAuth 연결이다. 새 자격증명은 사용자가 안전한 설정 화면에서 입력해야 한다. ChatGPT 연결 도구의 계정 권한이 스튜디오로 자동 이전되는 것으로 취급하지 않는다.
5. 후속 대화에는 완료 단계, 커밋, 검사 ID, 남은 한 단계만 전달한다. 전체 코드·이미지 데이터·전체 로그를 채팅에 되풀이하지 않는다.
