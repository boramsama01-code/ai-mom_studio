# 채널별 AI · 가족 대화 카드 8장 · Canva 연결

확인 기준: 2026-11-04, main `8914537766ac3f1c48a9b484b8c0ae29ea77e2be`, PR #63.
사용자 제공 **최종 통합 가이드 v1.1** 및 이후의 포인트 색상·썸네일·[읽는 뉴스 레퍼런스](https://brunch.co.kr/@leewooyeon/7)를 반영한다. 기존 역할 설정·수동 편집·배경 자산·복구 코드를 보존하고 새 데이터 형식을 추가했다. 운영 28번 콘텐츠는 읽기만 했으며 자동 변환하지 않았다.

## 완료 상태를 읽는 기준

- **구현**은 현재 작업 분기의 코드 상태다. 실제 배포 버전·CI는 PR의 정확한 head SHA와 배포 기록으로 확인한다.
- 실제 Canva 디자인 4개와 각 8장의 편집 가능한 문구·이미지 요소를 만들었다. 최종 글꼴·필드 라벨·배치는 편집 트랜잭션의 초안이다. Canva 도구가 요구하는 사용자 미리보기 승인 후 영구 저장해야 한다.
- **8장 Canva 자동화 인수 완료를 주장하지 않는다.** 저장 후 실제 dataset, 스튜디오 계정의 권한, 테스트 Autofill, PNG 8장 export, 스튜디오 재가져오기와 게시 파일 해시 일치를 확인해야 한다. 모의 응답 검사는 이를 대신하지 않는다.
- 실제 Instagram 게시, 운영 콘텐츠 삭제, 유료 AI 생성 테스트를 실행하지 않았다.

## 운영자가 사용하는 순서

### 1. 채널 설정

상단에서 채널을 선택하고 **설정 → 역할별 AI**를 저장한다. 새 기본 구성은 기사 분석·자료 검색 Gemini, 카드 문구 GPT, 이미지 생성 OpenAI 이미지다. 캡션·이미지 지시문·최종 검수는 카드 모델을 상속하며 따로 바꿀 수 있다. 기존에 명시한 모델 설정은 덮어쓰지 않는다. ChatGPT 구독은 API 연결을 대신하지 않는다.

검색은 실제 도구를 지원해야 한다. 모델 기억으로 논문·전시 주소를 만들어 추천하지 않는다. 집 활동은 항상 제공하고 확인한 추가 자료는 최대 1개다. 방문 추천은 기본 꺼짐이며 지역을 명시해야 한다.

### 2. 원문에서 자동 제작

원문 본문을 확인하고 자동 제작을 실행한다. 새 원고는 **표지 → 뉴스 요약 → 한 문장 시사점 → 중심 질문 → 두 시선 → 개념 → 활동 → 닫는 표지**다. 원문 없는 상태를 정상적인 기사 분석처럼 진행하지 않는다.

기존 원고 재작성은 제안을 먼저 보여 준다. 사용자가 편집한 칸은 잠금·대상 hash·원고 버전을 확인해 적용한다. 원문·요약을 다시 불러와도 기존 문구와 배경을 묵시적으로 교체하지 않는다.

### 3. 한 화면에서 세부 수정

각 칸을 직접 고치거나 필요한 칸·장만 다시 제안받는다. 두 시선은 상하 배치가 기본이다. 가치 개념은 두 정의와 경계 사례, 과학 개념은 확인된 통용 정의와 예시·비예를 쓴다. 과학적 사실을 근거 없는 반대 의견과 동등하게 배열하지 않는다.

뉴스 요약의 사실이나 과학 정의를 직접 고치면 **원문 근거 확인**에서 현재 원문·검증 자료의 발췌를 읽고 해당 칸의 근거를 다시 연결한다. 실제 근거의 사실·발언·전망 유형을 유지하며 임의 ID나 URL을 만들어 넣지 않는다. 이 과정은 AI를 호출하지 않는다. 수정하지 않은 다른 사실 칸의 연결은 유지한다.

**이 페이지 배경**에서 선택한 장의 그림을 생성·업로드·붙여넣고 초점·밝기·어둡기를 조절한다. 문구와 그림은 별도 데이터다. 미리보기와 단순 저장은 AI를 호출하지 않는다. 응답을 놓치면 기존 요청부터 조회한다.

편집기의 **문구 배치 미리보기 · 스튜디오 초안**은 자체 렌더다. Canva 콘텐츠의 최종 결과는 실제 export 이미지다. 서로 같은 결과라고 표시하지 않는다.

### 4. Canva로 실제 8장 만들기

처음 한 번 **디자인 → Canva 8장 마스터**에서 연결을 확인하고 준비된 4개 디자인을 각각 **이 마스터 검사·등록**한다. 실제 계정 기능·8페이지 규격·고정 페이지 ID·dataset 이름과 타입·마스터 수정 시각을 검사한다. 링크가 있다는 이유로 사용 가능이라고 표시하지 않는다.

원고를 저장한 뒤 **Canva 8장 만들기**를 실행한다. 개념 모드·추가 자료에 맞는 등록 마스터를 골라 새 디자인을 만든다. PNG 8장을 영구 자산으로 저장하고 게시용 JPEG 8장을 한 번 변환한다. 최종 미리보기와 승인에는 같은 JPEG의 ID·순서·해시를 쓴다.

Canva에서 직접 수정했다면 **최신 디자인 가져오기**를 누른다. 8장이 모두 로드되고 모든 문구를 스튜디오 원고와 대조한 뒤 적용한다. 편집 링크를 열었다고 동기화 성공을 표시하지 않는다. 완전한 양방향 텍스트 추출을 구현했다고 주장하지 않는다.

준비된 마스터는 상하 두 시선 배치다. 좌우 배치는 자체 렌더에서 사용할 수 있다. Canva를 자체 렌더로 바꾸면 명시적인 선택과 새 revision을 기록한다. 기존 정상 Canva 파일은 삭제하지 않는다.

Canva 마스터의 중앙 정렬·밝은 글자색·8장 고정 브랜드 배치는 자동 채우기로 바뀌지 않는다. 적용할 수 없는 흰색·밝은 단색·왼쪽 정렬·별도 닫는 표지 배경은 생성 전에 안내하며 저장한 입력을 지우지 않는다. 닫는 표지는 명시적인 버튼으로만 승인 배치를 다시 적용할 수 있다. Canva에서 직접 바꾼 결과는 가져오기·대조 경로로 확인한다.

### 5. 캡션·게시 준비

카드 문구와 Instagram 캡션은 따로 저장한다. 부모 대화 순서와 발화를 검토하고 계정을 확인한다. AI 한도·인증·일시 오류 시 기존 캡션 입력란에서 직접 저장한 뒤 현재 원고와 대조·확정할 수 있다.

캡션만 바뀌고 카드·배경·근거가 모두 같으면 검증된 PNG/JPEG 8장씩을 새 revision에 재사용한다. AI·Canva 내보내기는 다시 호출하지 않는다. 새 캡션에는 다시 검토·승인이 필요하다.

이미지·원고·캡션의 버전이 맞으면 기존 즉시 게시·예약·취소·실패 재전송 흐름을 쓴다. 실제 Instagram 전송 성공은 모의 검사만으로 증명하지 않는다.

## 데이터와 복구 계약

- `shared/familyDialogue.ts`는 작성 데이터, `shared/canvaEditorial.ts`는 평면 필드 어댑터다. 작성 AI의 출력 스키마를 Canva 라벨로 바꾸지 않는다.
- evidence set과 단계별 실행 영수증은 원문·검색의 불변 스냅샷, 모델·입력 hash·사용량 제공 여부를 기록한다.
- `canva_masters`는 채널·변형·템플릿 버전·dataset hash·페이지 ID·수정 시각·계정/팀을 저장한다.
- `canva_render_jobs`는 입력 revision·UUID/hash·외부 ID·lease·단계·결과를 저장한다. 재시작 시 알려진 ID는 조회부터 재개한다.
- `canva_asset_uploads`는 계정/팀과 이미지 hash별 업로드 결과를 재사용한다. 미확정 업로드는 자동 재전송하지 않는다.
- `media_assets`에 원본 PNG 8장과 게시 JPEG 8장의 bytes·hash·소유권·revision을 저장한다. 임시 다운로드 URL을 예약 게시 원본으로 쓰지 않는다.
- 외부 호출 전에 접수 시도를 기록한다. ID를 못 받은 네트워크 실패는 `result_unknown`이다. 새 UUID·원고 버전으로 중복 생성을 우회할 수 없다.
- 실제 디자인을 찾으면 기존 디자인 연결로 복구한다. 계정·팀·소유권·8장 규격·수정 시각·원고 CAS를 검사하고 새 Autofill 없이 export한다. 항상 대조 단계에서 멈춘다.
- 만료된 export 재요청은 명시적 동작과 기존 ID CAS로 제한한다. 원고·템플릿·계정·디자인 변경, 한도, 인증, 결과 미확정을 구분한다.
- 준비된 고정 마스터의 텍스트 사전 점검은 문구를 자르거나 축소하지 않는다. 초과 칸을 알리고 원고를 보존한다. 보수적인 글자·줄 추정이며 실제 Canva 8장 확인을 대신하지 않는다.

## 검증·배포·롤백

`npm run typecheck`, `npm test`, `npm run build`를 사용한다. CI의 실제 PostgreSQL 16에서 CAS·소유권·중복·재시작·출력 자산·캡션 재사용을 검사한다. WebKit 320·393·1280px에서 저장·재열기·늦은 제안·배경·가로 넘침을 확인한다. 브라우저 AI/Canva API는 모의 응답이며 실제 외부 성공과 구분한다.

실제 외부 인수는 승인된 마스터 dataset → 격리된 예시 Autofill → PNG 8장 저장 → 수동 수정 재가져오기 → 최종 미리보기/게시 hash 비교다. AI 품질·Instagram 송신·실기기 키보드/IME는 추가 확인 범위다.

0016은 역할 설정, 0017은 v2 근거·실행 기록, 0018은 Canva 마스터·작업·업로드 캐시 migration이다. 기존 콘텐츠 일괄 변환·삭제는 없다. 전체 CI를 통과한 정확한 head만 병합하고 Render commit·health·기존 28번 보존을 확인한다.

**v2 원고 저장 후에는 v2를 보존하지 못하는 구버전으로 단순 롤백하지 않는다.** 문제가 있는 경로를 중지하고 v2 읽기·수동 저장·기존 자산을 보존하는 수정 배포를 우선한다. 근거·원고·이미지를 지워 복구하지 않는다.

## SaaS 공개 판매 전 외부 제약
